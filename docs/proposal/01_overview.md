# 第 1 章 项目概述

> 本章用一页回答评委最关心的四个问题：我们是谁、做什么、为什么值得做、商业价值多大。
> 所有数字与第 5 章《商业潜力》同源同值，首次出现处标注 [C1]–[C8] 溯源标签
> （含义见第 5 章附录），假设性与未取得内容均如实标注。

## 1.1 一句话定位

**Claim2Value 是面向券商研究所、产业基金与一二级分析师的"人形机器人产业链证据链
分析智能体"**：用户以对话方式提出研究问题，系统输出两类结果——一是**可回溯到原始
披露证据的分析结论**（Claim Bank，每条主张带来源、页码、摘录、口径与置信度分级），
二是**事件到财务影响的量化传导**（三情景估值模型原型），全流程推理留痕、开源可审计。

本项目的差异化不是"又一个金融数据终端"，而是把**论证质量本身**做成产品：机器负责
证据的组织、核验与量化传导，人负责判断与决策。

## 1.2 痛点：现有工具解决不了什么

当前卖方研究工具定价不低——Wind 约 3.98 万元/账号/年、慧博 0.9–2 万元/年、
AlphaSense/Tegus 海外席位 1–2.5 万美元/年起 [C6]——但存在四个共性缺口：

1. **证据不可回溯**：结论无法一键定位到原始公告/纪要/数据页；
2. **无财务影响量化**：事件 → 营收/利润/估值影响的量化链条缺失；
3. **黑盒结论**：不给推理路径，无法审计；
4. **重数据轻论证**：数据终端强、逻辑链弱，"读证据—建论点—交叉验证"仍全靠人肉。

Claim2Value 按此四点反向设计（详见第 2 章与第 5 章 5.6.2）。与此同时，LLM API 成本
（Claude Sonnet 级 2/10 美元每百万 token，输入/输出）[C6] 较传统席位费**低 3–4 个
数量级** [C6]，为"证据链 + 量化影响"的差异化定位留出巨大成本与毛利空间。

## 1.3 方案总览：三个模块对应三个缺口

| 模块 | 功能 | 对口的缺口 | P1 交付状态 |
|---|---|---|---|
| 对话式分析 | 自然语言提问 → 产业链证据检索与组织 | 重数据轻论证 | 已交付 |
| Claim Bank 证据链 | 每条主张带来源/页码/摘录/口径/置信度，核验人必填硬校验 | 证据不可回溯、黑盒结论 | 已交付（19 条 Claim、5 条已人工核验回填） |
| 财务影响量化 | 事件变量 → 三情景营收/估值传导（原型） | 无财务影响量化 | 已交付（绿的谐波三情景估值原型） |

三条能力均由一条开源 pipeline 串起：从原始公告 PDF 到 Claim Bank 到报告全自动化、
全链路留痕，可被任何机构自行审计与复现。

## 1.4 为什么是这条产业链、为什么是现在

**赛道本身正在商业化爆发。** 以切入环节谐波/RV 减速器为例：中国工业机器人减速器
市场 2023 年约 45.6 亿元（谐波 16.0 + RV 29.6）[C1]，人形机器人量产预期使其 2030 年
TAM 达 71–603 亿元、2035 年达 1050–4394 亿元（三档测算）[C2]。分析对象的市场规模
膨胀，直接放大"看得懂这条链"的研究服务的价值。

**赛道里存在可被本产品持续捕捉的预期差。** 以样板标的绿的谐波（688017）为例：
2024 年谐波减速器 ASP 已降至 1293 元/台（-15.0%）[C5]，而多家券商盈利预测仍采用
约 1500 元/台的降价假设——**主流预测对价格下行速度系统性低估** [C5]；销量侧
2025 年 +72.5% [C4] 与产能侧定增项目进度仅 6.08%、延期至 2028 年底 [C4] 两个
事实同时成立，市场叙事集中于前者。市值 512.96 亿元、PE(TTM) 365.83 [C3] 的定价
意味着市场在为"量产期权"付费——**假设与证据之间的每一条裂缝，都是研究服务的
价值来源**。

**卖方研究正处于预算收紧的替代窗口。** 2024 年券商研究佣金 198.65 亿元，
同比 -22.48% [C8]，分析师人均产出要求上升，AI 工具的采购逻辑从"锦上添花"转向
"降本刚需"。

## 1.5 商业一页

- **TAM（供给侧主口径）**：中国券商研究佣金盘子 198.65 亿元/年 [C8]；
  全球金融数据/研究支出 420 亿美元（2023）[C8]；需求侧口径见 1.4 的减速器
  TAM 三档测算 [C1][C2]。
- **SAM**：按研究佣金比例法（198.65 亿 × 1–3%）测算约 **2–6 亿元/年**，
  人头法（0.6–2.3 亿）与机构法（约 4 亿）交叉验证收敛 [C8]。
- **SOM**：三年目标为 SAM 的 2–5%，即 **400–3000 万元/年** ARR。
- **定价**：个人版 1.2 万/年、团队版 6–10 万/年、机构版 20 万+/年，
  下锚慧博、上锚 Wind [C6]。
- **成本与毛利**：LLM API 仅占总成本小头 [C6]，按团队版 8 万/年、单团队年 API
  成本 < 2000 元估算，规模化后毛利率可达 85%+（数据源授权成本为主要不确定项，
  标注为假设）。
- **ROI 叙事**：人形产业链分析师年薪 40–80 万元，工具每周节省 4 小时即年化
  价值 4–8 万元，个人版定价 1.2 万元/年 ROI 清晰（假设性测算，详见第 5 章 5.7.2）。

## 1.6 团队

团队由两位核心成员构成，能力恰好接成一条"验证型研究 pipeline"：

- **经济与金融方向成员**：经济机制建模、实证识别、因果推断、产业/政策解释与
  金融映射，负责财务影响量化模块与产业链知识框架；
- **Agent 工程方向成员（上海交大 SPEIT 孙圣尧）**：Agent Reliability、Agent
  Evaluation、Tool-state Verification、Benchmark Design 与结构化输出鲁棒性，
  负责证据链引擎、核验硬校验与评测体系。

两人共同点都是"验证派"：一个验证经济论证，一个验证 Agent 输出——这与本项目
"可审计、可回溯"的产品内核同源。

## 1.7 诚实边界

本项目已交付的是**工程原型与证据链 pipeline**（P1 阶段），估值模块为公开数据构建的
**原型情景**（`model_status = prototype_scenario_not_investment_recommendation`），
不构成任何投资建议；模型 EV（32–86 亿元）与市场市值（513 亿元）相差约一个数量级，
我们不假装模型可以解释市值，而输出"隐含预期 ↔ 可验证证据"的对照表（详见第 5 章
5.5.3 与第 8 章）。SAM 比例假设、毛利测算中的标注性假设均已明示。产品尚未进入
商业付费阶段，SOM 为三年目标而非现状（假设性目标）。
