## 6.3 中期里程碑（6–18 月，放大期）

与 5.7.4 对齐的商业目标：**100 家机构、ARR 1000 万元，扩展到 RV/丝杠/电机全链**。

- **产业链扩展**：新增环动科技（RV）、双环传动、步科等标的的案例切片，
  复用现有 pipeline 与 Claim Bank 写回流程（数据管道已开源，边际成本低）；
- **团队版产品化**：多人席位 + Claim Bank 协作 + API（对应 5.7.2 团队版
  6–10 万元/年档位）；接入实时检索与自动 Claim 提取（TODO P2）；
- **数据层规模化**：从本地 PDF 扩展到公告自动采集 + 本地缓存，
  降低人工搜集占比；
- **模型升级**：经复核的 ontology 系数进入正式财务模型；引入"隐含预期反推"
  分析任务（对应 5.5.3 的 EV↔市值差距处理）。

## 6.4 规模期里程碑（18–36 月）与资源需求

与 5.7.4 对齐的商业目标：**SAM 的 2–5%，即 400–3000 万元 ARR，平台化 + API 生态**。

阶段任务：机构版（20 万元+/年，私有证据接入 + 模型白盒审计）上线；
自定义产业链配置（客户自选监控环节）；API 生态对接卖方内部系统。

资源需求（粗估，随试点反馈修正）：

| 类别 | 0–6 月 | 6–18 月 | 18–36 月 |
|---|---|---|---|
| 人员 | 工程 2 + 金融 2 + 运营 1 | 工程 4 + 金融 2 + 商务 2 | 工程 6 + 金融 3 + 商务/客服 4 |
| 算力 | 现有 LLM API（<2000 元/团队/年量级，见 5.7.3） | API + 向量检索基础设施 | 私有化部署选项 |
| 数据授权 | 公开披露为主，成本近零 | 公告数据源授权起步 | Wind/公告授权计入机构版定价（见 5.8） |
| 预算大头 | 人力 | 人力 + 数据授权 | 数据授权 + 合规 |

## 6.5 关键依赖与外部风险

1. **数据源授权（最大不确定项）**：Wind/公告数据的版权边界需在机构版落地前
   明确；当前以公开披露数据为主规避，授权成本已计入机构版定价假设
   （5.7.3 毛利率 85%+ 的标注项）。若授权成本超预期，毛利率目标需下修。
2. **合规资质**：投资顾问资质边界——产品输出"证据对照"而非"投资建议"的
   表述纪律已写入模型（`model_status` 限定），但面向付费客户仍需法律意见
   确认免责结构（5.8）。
3. **人形量产节奏**：GGII 与高盛 2030 年销量预测差 2.6 倍 [C2]，预测分歧本身
   是需求而非纯风险（产品价值绑定"多口径跟踪"），但若行业整体降温，
   试点转化率需重估。
4. **竞品复制**：Wind/同花顺具备 AI 研发能力；对冲是证据链数据资产 +
   审计留痕 + 开源 pipeline 建立的信任（5.8）。
5. **团队复核瓶颈**：M1/M4 依赖经济金融成员的人工核验产能，
   是近期路线图最可能滑期的环节——若滑期，试点以 14 条已验证 Claim 的
   案例报告先行，不等全量回填。
