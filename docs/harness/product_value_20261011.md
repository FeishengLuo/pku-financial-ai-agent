# 研究工作台：解决的问题与当前边界

本次对照实际代码检查，而非按产品设想描述。工作台面向需要准备研究底稿的研究助理、金融课程项目组，以及已有数据的量化研究者。使用者可以选择自己的模型；本机工具负责校验、计算与保存记录。

## 已实现什么

| 使用者的问题 | 输入与处理 | 可拿走的成果 |
|---|---|---|
| 公司说产品或扩产能改善盈利，材料支持吗？ | 上传公告、年报、技术资料；确认披露日、公司和产品范围；按条件检索、匹配摘录并并列支持与反证 | 带来源定位的候选、未完成范围、待核对事项 Excel |
| 财务数字是否可比，利润为什么变化？ | 标准财务长表或模型提取候选；核对16列、单位、合并／母公司、期间、日期和版本；满足条件后比较两期 | 标准表、质量报告、历史比率、盈利变化底稿 |
| 估值需要什么业务兑现条件？ | 明确确认销量、价格、成本、产能、投产时间及现金流假设；本地检查约束并计算 | 条件冲突、正向情景、反推和敏感性结果；冲突会暂缓计算 |
| 策略的好结果是不是数据或费用造成的？ | 上传完整日频面板；先体检，再按动量或已有因子排序，T日收盘信号、T+1收盘成交、T+2首笔收益 | 数据问题表、净值、持仓、回撤、交易费用、同费率基准；按需运行预先声明的参数比较 |

产能、时点、交易和费用由本地规则处理，不由模型随意写出收益或估值。模型负责计划与候选整理；引用文字匹配只说明能在本次材料中找到文字，不认证语义、来源权威性或论点成立。

## 本轮增加的具体用处

**待核对事项清单**：把反证冲突、模型提出的缺口、未来预测、参数确认与未运行条件分别登记。部分审查失败也能导出明确的未完成项。模型说缺少订单并不能证明公司没有订单，因此缺口仍标为待核实。

**量化数据体检**：无API即可检查重复行、无效日期、代码前导零、价格、缺失组合、因子值和带时区的可得时间。每类给总数量与最多20个例子；导出Excel。它不猜代码、不补价格、不删更正行，也不核验官方交易日历。收盘后才可用的因子与回测规则一致：提示并屏蔽当日信号，不改写发布时间。

**模型与套餐入口**：说明预设、地址、密钥来源、区域和账号权益，获取实际模型列表或手填控制台ID。切换服务清除旧密钥；不把上一个服务的连接成功用于新服务。说明项不能直接调用。网页、编程套餐与开放API不是可互换的凭据。

## 新用户如何开始

1. 首页选具体问题；暂时不知道如何提问，点“教程与示例”。合成样例可直接载入，运行本地计算无需购买模型。
2. 需要自动提取或证据审查时，再打开“模型与套餐”确认账号类型，按三步连接。
3. 上传自己的材料，按附近提示逐项填来源。按钮尚未启用时，页面列出缺什么；估值和诊断按需开启。
4. 运行后先看问题和缺口，再看数字；下载底稿。在“成果记录”可重新下载已保存的本机输出。

## 是否有价值、下一步怎样检验

当前可检验的价值是减少底稿整理、找出格式与口径错误、显式保留反证，以及让计算假设能够复查。本轮没有测量真实用户节省的时间，也没有得到投研结论准确率；通过自动化测试不能代替这两项。

下一轮优先让同学用自己的一个真实研究问题走通：记录首次连接耗时、人工修正次数、是否发现有用的反证或口径问题，以及导出的底稿是否可继续工作。之后再选最影响完成任务的一项，例如扫描文件OCR、跨会话恢复或自有数据适配；当前三项均未实现。没有必要先堆积更多功能名称。

当前不含自动市场／数据库取数、实盘交易、多用户协作和网页登录授权。完整面板回测未模拟涨跌停、停牌成交、容量及冲击成本；样本收益和假设情景不是预测效果证据。新工作台尚未替换旧01—07正式材料，冻结技术题没有改变。
